# デザインの成果物

見た目と体験の方向を決めてもらうために agent が作ったモックと、bannzai から受領したデザインの置き場。Claude Design の canvas (claude.ai/artifact) はアカウントの切り替え・削除で開けなくなるため、canvas に公開したファイルをここに保存する (create-new-app skill Phase 7)。

- `mock-<日付>/canvas.json` と `*.dc.html`: canvas に公開した artboard の原本。`.dc.html` は canvas の実行環境 (`./support.js`) を前提にしていて単体では表示できない
- `mock-<日付>/index.html`: 同じ artboard を単独で開ける形に並べたもの。ブラウザで開いて見る
- 決まった見た目の方向は `documents/DIRECTION.md`「デザインの方向」に書く
