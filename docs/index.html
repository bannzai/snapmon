撮った写真が
自分だけのモンスターになる

身の回りの物にカメラを向けると、その物に似たモンスターが生まれます。属性の相性と技で勝敗が決まるターン制バトルで、集めて、戦わせて、見せ合おう。

近日公開 App Store・Google Play・Web 版を準備中です。

snapmon でできること

撮った物が、モンスターに

カメラで撮るか、アルバムから選ぶだけ。被写体の特徴から名前と図鑑の文章、属性、技、ステータスが決まります。一度生まれたモンスターは後から変わりません。

ステータスが効くバトル

素早さの順に行動し、技の威力、属性の弱点、攻撃と防御、技の残り回数が勝敗に効きます。バトルのたびにレベルが上がります。

集めて、見せ合う

図鑑にはモンスターと元の写真が並びます。元の写真は自分だけに表示されます。図鑑のカードやバトルの結果は SNS に共有できます。

遊び方

  1. 身の回りの物を撮る、またはアルバムから選ぶ。
  2. 生まれたモンスターを図鑑に登録し、手持ちの 3 体を選ぶ。
  3. CPU や他のユーザーの手持ちと、ターン制バトルで戦う。
