撮った写真が
自分だけのモンスターになる

身の回りの物にカメラを向けると、その物に似たモンスターが生まれます。属性の相性と技で勝敗が決まるターン制バトルで、集めて、戦わせて、見せ合おう。

ブラウザで開いて遊べます。iOS・Android のアプリは準備中です。

SnapMonster でできること

身の回りの物を撮るだけ

カメラで撮るか、アルバムから写真を選ぶだけ。写真から切り出した被写体が、そのままモンスターの姿になります。被写体の特徴から名前と図鑑の文章、属性、技、ステータスが決まります。

ステータスと相性で勝負が決まる

素早さの順に行動し、技の威力、属性の弱点、攻撃と防御、技の残り回数 (PP) が勝敗に効きます。手持ちの 3 体で CPU トレーナーと戦い、バトルのたびにレベルが上がります。

集めて図鑑を埋めよう

生まれたモンスターは図鑑に残ります。一度生まれたモンスターの姿と能力は後から変わりません。

生まれたモンスターを見せ合おう

図鑑のカードやバトルの結果を画像にして SNS に共有できます。モンスターの絵は元の写真の一部または全体のことがあり、共有したカードを見た人にも見えます。

遊び方

  1. 身の回りの物を撮るかアルバムから選ぶ
  2. 生まれたモンスターを図鑑に登録して手持ちの 3 体を選ぶ
  3. CPU トレーナーとターン制バトルで戦う

安心して遊ぶために

  • 不適切な写真からはモンスターを生成しません
  • 人が写る写真から生成した時は注意を出します
  • 他の人が写る写真はその人の同意を得てから使ってください
  • 対象年齢は 13 歳以上です
