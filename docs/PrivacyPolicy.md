# プライバシーポリシー

bannzai（以下「提供者」といいます。）は、提供者の提供するゲーム「snapmon」（以下「本サービス」といいます。）における、ユーザーについての個人情報を含む利用者情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます。）を定めます。

## 収集する利用者情報および収集方法
本ポリシーにおいて、「利用者情報」とは、ユーザーの識別に係る情報、通信サービス上の行動履歴、その他ユーザーまたはユーザーの端末に関連して生成または蓄積された情報であって、本ポリシーに基づき提供者が収集するものを意味するものとします。

### 本サービスの利用を通じてユーザーからご提供いただく情報
- 初回起動時の年齢確認で入力する生年月
- ユーザーが撮影またはアルバムから選択する写真（人物や、人物を特定できる情報が写ることがあります）
- 写真から作成する被写体の説明文（何か・色・素材・大きさ・硬さなど。AI が作成し、モンスターの属性・技・ステータスの判定と同じ被写体の判定に使います）と、写真のハッシュ値（同じ写真の判定に使う値）
- 写真から生成されたモンスターの情報（名前、図鑑の文章、属性、技、ステータス、レベル、生成したモンスターの画像）
- 手持ちの編成、バトルの結果その他本サービスの利用の記録
- 不適切なコンテンツの通報の内容、ユーザーのブロックの記録

### 他のサービスからご提供いただく情報
ユーザーが、データの引き継ぎのために Apple ID・Google アカウントとの連携を許可した場合には、その許可の際にご同意いただいた内容に基づき、以下の情報を当該外部サービスから収集します。
- 当該外部サービスでユーザーが利用するID
- メールアドレスと表示名（連携時にプロバイダから提供されることがあります。Apple の場合、メールアドレスは Apple が発行する転送用のものになることがあり、表示名は初回のサインインでだけ提供されます。Google の場合の提供範囲は未確認のため、メールアドレスと表示名が提供されることがあるものとして扱います）[^authprovider]
- その他当該外部サービスのプライバシー設定によりユーザーが連携先に開示を認めた情報

連携を行わない場合、本サービスは Firebase Authentication の匿名ログインでユーザーを識別します。この場合、氏名・メールアドレス等は収集しません。

[^authprovider]: 出典: https://firebase.google.com/docs/auth/web/apple 「Apple only shares user information such as the display name with apps the first time a user signs in.」「Apple provisions a unique email address for that user」（2026-10-21 に確認）。Google は https://firebase.google.com/docs/auth/web/google-signin に提供される項目の記載を確認できなかったため、未確認としています

### 提供者が収集する情報
ユーザーが本サービスを利用するにあたって、提供者が収集する情報。提供者は、本サービスへのアクセス状況やそのご利用方法に関する情報を収集することがあります。これには以下の情報が含まれます。
- 端末の種類・OS のバージョン、アプリのバージョン
- 生成・バトル・共有などの利用状況（Google Analytics for Firebase による）
- アプリが異常終了した際のクラッシュ情報（Firebase Crashlytics による）
- IPアドレス、リファラ、サーバーアクセスログに関する情報

## 写真の取扱い
- ユーザーの元の写真は、そのユーザー本人の図鑑にだけ表示します。他のユーザーには表示せず、共有カードにも入れません。
- 生成したモンスターの画像・名前・属性・技・ステータスは、認証済みの他のユーザーが閲覧でき、対戦（PvP）と共有で表示されます。
- 写真は、モンスターの生成の前に Google Cloud Vision API で、露骨な内容・暴力的な内容・顔の検出・ラベル（写っている物の種類）の判定を受けます。露骨な内容または暴力的な内容を含むと判定された写真と、顔が写る写真からは、モンスターを生成しません。顔が検出された写真は Anthropic の Claude API に送信しません。生成したイラストにも露骨な内容の判定をかけ、該当する場合は仮の絵に差し替えます。
- 不適切と判定された写真と、同じ被写体の重複と判定された写真は、その時点で削除します。
- 他人が写っている写真、他人の権利を侵害する写真を送信しないでください（利用規約を参照してください）。

## 利用目的
本サービスのサービス提供にかかわる利用者情報の具体的な利用目的は以下のとおりです。
- 13 歳未満の方が本サービスを利用できないようにするため（年齢確認の生年月の確認）
- ユーザーが撮影・選択した写真からモンスターを生成し、図鑑・手持ち・バトルで利用するため（AI による画像の解析、文章の生成を含みます）
- 同じユーザーによる同じ被写体の二重登録を防ぐため
- 不適切な写真の判定、通報への対応、悪質なユーザーへの対応のため
- 本サービスに関する登録の受付、ユーザー認証、データの引き継ぎ、ユーザー設定の記録等本サービスの提供、維持、保護および改善のため
- ユーザーのトラフィック測定および行動測定のため
- 不具合の調査・修正のため
- 本サービスに関するご案内、お問い合わせ等への対応のため
- 本サービスに関する提供者の規約、ポリシー等（以下「規約等」といいます。）に違反する行為に対する対応のため
- 本サービスに関する規約等の変更などを通知するため

## 外部サービスの利用
本サービスは、サービスの提供にあたり以下の外部サービスを利用します。各サービスに送信された情報は、各社のプライバシーポリシー・利用規約に基づき管理されます。

- **Firebase (Google LLC)**: 次の機能を利用します。 https://policies.google.com/privacy?hl=ja
  - Firebase Authentication: 匿名ログインと Apple / Google アカウントとの連携によるユーザーの識別
  - Firebase App Check: 正規のアプリ以外からの呼び出しを防ぐための検証。Apple では App Attest / DeviceCheck、Android では Play Integrity、Web では reCAPTCHA Enterprise を利用します
  - Cloud Firestore: 図鑑・手持ち・PvP で相手に見せるデータ・通報とブロックの記録の保存
  - Cloud Storage for Firebase: ユーザーの元の写真と生成したモンスターの画像の保存。元の写真は本人だけが読み出せるよう制限します
  - Cloud Functions for Firebase: 下記の外部サービスを呼び出すサーバー処理（API キーを端末に置かないために使います）
  - Firebase Hosting: Web 版の配信
  - Google Analytics for Firebase: 利用状況の分析
  - BigQuery エクスポート: Google Analytics for Firebase の利用状況のイベントを、提供者の BigQuery に保存して集計します（保存期間は「保存期間」を参照してください）
  - Firebase Crashlytics: クラッシュ情報の収集
- **Anthropic, PBC (Claude API)**: ユーザーが撮影・選択した写真のうち、顔が検出されなかったものは、Cloud Functions を経由して Anthropic の Claude API に送信され、被写体の説明、モンスターの名前、図鑑の文章の生成に利用されます。顔が検出された写真は送信しません。 https://www.anthropic.com/legal/privacy [^anthropic]
- **Google Cloud Vision API (Google LLC)**: ユーザーが撮影・選択した写真は、露骨な内容・暴力的な内容の判定（SafeSearch）、顔の検出、写っている物のラベルの検出のために Cloud Vision API に送信されます。生成したイラストも、露骨な内容の判定（SafeSearch）のために送信されます。 https://policies.google.com/privacy?hl=ja [^vision]
- **画像生成 API**: モンスターのイラストの生成に利用する予定です。サービスは選定後にこのポリシーに追記します
- **TypeSafe の Jev (TypeSafe)**: Claude API が作成した被写体の説明文（文字列）が、モンスターの属性・技・ステータスの判定のために Jev に送信されます。写真そのものは送信しません。 https://docs.typesafe.ai/models.md [^jev]

[^anthropic]: 出典: https://privacy.claude.com/en/articles/7996868-is-my-data-used-for-model-training 「By default, we will not use your inputs or outputs from our commercial products ... to train our models.」（2026-10-21 に確認。API の利用が「commercial products」に当たるかは同ページの定義に従い、提供者が確かめた範囲では上記の記載のとおりです。Anthropic 側の保存期間は同社のポリシーに従います）
[^vision]: 出典: https://docs.cloud.google.com/vision/docs/data-usage 「Google does not use the content you send to train and improve our Cloud Vision features」、オンラインのリクエストについて「the image data is processed in memory and not persisted to disk.」、「Google also temporarily logs some metadata about your Vision API requests」（2026-10-21 に確認）
[^jev]: 出典: https://docs.typesafe.ai/models.md 入力は「Text」、「Jev is not trained on customer requests or responses.」（2026-10-21 に確認）

## 保存期間
ユーザーの利用者情報（写真、生成したモンスター、図鑑、手持ち、バトルの記録、通報・ブロックの記録）は、ユーザーがアカウントを削除するまで保存します。アカウントは、アプリの「設定」画面の「アカウントを削除」から、いつでも削除できます（アプリを操作できない場合は bannzai.app@gmail.com へご連絡ください）。アカウントを削除すると、上記のデータはすみやかに削除され（一部の写真は再試行のため時間がかかることがあります）、復元できません。手順の詳細と削除されるデータは[アカウントの削除について](AccountDeletion)を参照してください。利用状況のイベント（Google Analytics for Firebase）は、提供者の BigQuery に最大 90 日間保存します。Google Analytics for Firebase 側とクラッシュ情報（Crashlytics）は、Google の定める期間に従って保存されます。不適切または重複と判定された写真は、判定の時点で削除します。

## 対象年齢と子どもの個人情報（COPPA 等の順守の方針）
- 本サービスの対象は 13 歳以上です。初回起動の最初の画面で年齢確認（生年月の入力）を行い、13 歳未満の方は利用できません。
- 年齢確認より前に、ユーザーの識別子を取得しません（Firebase Authentication・Google Analytics for Firebase・Firebase App Check を、年齢確認の完了後に初期化します）。確認の結果は、サーバー側でも検査します。
- 提供者は、13 歳未満の子どもから、その保護者の検証可能な同意を得ずに個人情報を収集しません。13 歳未満であることが判明した場合は、そのアカウントとデータを削除します。ご連絡は bannzai.app@gmail.com までお願いします。
- 提供者は、米国の児童オンラインプライバシー保護法（COPPA）をはじめ、適用される法令を順守します。
- 13 歳以上の未成年のユーザーは、親権者など法定代理人の同意を得たうえで本サービスを利用してください。
- 本サービスは、露骨な内容・暴力的な内容・顔が写る写真からモンスターを生成せず、通報とブロックの機能を備えています。モンスターの名前・図鑑の文章は AI が生成するものです。

## 通報とブロック
他のユーザーのモンスターを表示する対戦（PvP）で、不適切なコンテンツを通報する機能とユーザーをブロックする機能を提供します。通報の内容と対象のモンスターは、確認と対応のために提供者が確認します。通報されたモンスターは、対戦の相手の候補から外されることがあります。

## 通知・公表または同意取得の方法、利用中止要請の方法
ユーザーは、本サービスの所定の設定を行うことにより、個人情報の全部または一部についてその収集または利用の停止を求めることができ、この場合、提供者は速やかに、提供者の定めるところに従い、その利用を停止します。なお個人情報の項目によっては、その収集または利用が本サービスの前提となるため、アカウントを削除した場合に限り、提供者はその収集または利用を停止します。

## 個人情報の開示
提供者は、ユーザーから、個人情報保護法の定めに基づき個人情報の開示を求められたときは、ユーザーご本人からのご請求であることを確認の上で、ユーザーに対し、遅滞なく開示を行います（当該個人情報が存在しないときにはその旨を通知いたします。）。ただし、個人情報保護法その他の法令により、提供者が開示の義務を負わない場合は、この限りではありません。

## 個人情報の訂正および利用停止等
1. 提供者は、ユーザーから、(1)個人情報が真実でないという理由によって個人情報保護法の定めに基づきその内容の訂正を求められた場合、および(2)あらかじめ公表された利用目的の範囲を超えて取扱われているという理由または偽りその他不正の手段により収集されたものであるという理由により、個人情報保護法の定めに基づきその利用の停止を求められた場合には、ユーザーご本人からのご請求であることを確認の上で遅滞なく必要な調査を行い、その結果に基づき、個人情報の内容の訂正または利用停止を行い、その旨をユーザーに通知します。なお、訂正または利用停止を行わない旨の決定をしたときは、ユーザーに対しその旨を通知いたします。
2. 提供者は、ユーザーから、ユーザーの個人情報について消去を求められた場合、提供者が当該請求に応じる必要があると判断した場合は、ユーザーご本人からのご請求であることを確認の上で、個人情報の消去を行い、その旨をユーザーに通知します。アプリからのアカウント削除でも消去できます。
3. 個人情報保護法その他の法令により、提供者が訂正等または利用停止等の義務を負わない場合は、前2項の規定は適用されません。
