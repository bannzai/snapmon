# アカウントの削除について

アプリ「snapmon」（デベロッパー: bannzai）のアカウント削除手順と、削除されるデータについて説明します。

## アプリからアカウントを削除する手順

1. アプリを起動する
2. 「設定」を開く
3. 「アカウントを削除」をタップする
4. 確認ダイアログで「削除する」をタップする

削除を実行すると、その場でアカウントが削除されます。再度アプリを開くと、新しい匿名アカウントで始まります。

サインインしてから時間が経っている場合、セキュリティのため再ログインを求められることがあります。その場合は画面の案内に従って再度サインインしてから、もう一度削除操作を行ってください。

## 削除されるデータ

アカウント削除の操作により、次のデータが削除されます。

- アカウント情報（Firebase Authentication のユーザーアカウント）
- サインインに使用した認証情報（Apple ID / Google アカウントとの連携）
- 撮影・選択した元の写真
- 生成したモンスター（名前、図鑑の文章、属性、技、ステータス、レベル、画像）と図鑑・手持ち
- バトル（PvP を含む）の記録
- 通報・ブロックの記録

これらは削除操作と同時に削除され、削除後は復元できません。他のユーザーの対戦の相手の候補にも表示されなくなります。

## 削除後も保持されるデータ

提供者が保持するデータはありません。ただし、個人を特定できない形の利用状況の統計（Google Analytics for Firebase）とクラッシュ情報（Firebase Crashlytics）は、Google の定める期間に従って保存されることがあります。これらからアカウントを復元することはできません。

アプリを操作できない状態でアカウントの削除を希望される場合は、下記の連絡先までご連絡ください。ご連絡から 30 日以内に対応します。
