# アカウントの削除について

アプリ「snapmon」（デベロッパー: bannzai）のアカウント削除手順と、削除されるデータについて説明します。

## アプリからアカウントを削除する手順

1. アプリを起動する
2. 「設定」を開く
3. 「アカウントを削除」をタップする
4. 確認ダイアログで「削除する」をタップする

削除を実行すると、アカウントの削除がすぐに始まります。再度アプリを開くと、年齢の確認から始まり、新しい匿名アカウントで始まります。

サインインしてから時間が経っている場合、セキュリティのため再ログインを求められることがあります。その場合は画面の案内に従って再度サインインしてから、もう一度削除操作を行ってください。[^reauth]

[^reauth]: 出典: https://firebase.google.com/docs/auth/web/manage-users 「To delete a user, the user must have signed in recently.」「If you perform one of these actions, and the user signed in too long ago, the action fails with an error.」（2026-10-21 に確認）

## 削除されるデータ

アカウント削除の操作により、次のデータが削除されます。

- アカウント情報（Firebase Authentication のユーザーアカウント）
- サインインに使用した認証情報（Apple ID / Google アカウントとの連携）
- 撮影・選択した元の写真
- 生成したモンスター（名前、図鑑の文章、属性、技、ステータス、レベル、画像）と図鑑・手持ち
- バトル（PvP を含む）の記録
- 通報・ブロックの記録
- 写真から作成した被写体の説明文と写真のハッシュ値

これらは削除操作の後、すみやかに削除されます。一部の写真は、削除に失敗した場合に再試行するため、削除までに時間がかかることがあります。削除後は復元できません。他のユーザーの対戦の相手の候補にも表示されなくなります。

## 削除後も保持されるデータ

次のデータは、アカウントの削除後も残ることがあります。
- 利用状況のイベント（Google Analytics for Firebase）: 提供者の BigQuery に最大 90 日間保存されます。アカウントを識別する情報を含む場合があります。
- クラッシュ情報（Firebase Crashlytics）: Google の定める期間に従って保存されます。

これらからアカウントやモンスターを復元することはできません。
