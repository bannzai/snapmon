# アカウントの削除について

アプリ「snapmon」（デベロッパー: bannzai）のアカウント削除手順と、削除されるデータについて説明します。

## アプリからアカウントを削除する手順

1. アプリを起動する
2. 「設定」を開く
3. 「アカウントを削除」をタップする
4. 確認ダイアログで「削除する」をタップする

削除を実行すると、アカウントの削除がすぐに始まります。再度アプリを開くと、年齢の確認から始まり、新しい匿名アカウントで始まります。

iPhone・iPad で「データを引き継ぐ」から Apple ID と連携している場合は、Apple ID との連携を取り消すため、削除の途中で Apple のサインインを求められます。画面の案内に従ってサインインすると、そのまま削除が進みます。[^reauth]

モンスターを生成している途中は削除できません。生成が終わってから、もう一度削除操作を行ってください。削除の途中で通信に失敗した場合は画面にその内容が表示されるので、もう一度削除操作を行ってください。

[^reauth]: 出典: https://firebase.google.com/docs/auth/flutter/federated-auth 「Apple sign-in on Apple platforms returns an authorization code that can be used to revoke the Apple auth token」（2026-10-22 に確認）。この認可コードはサインインの結果にだけ含まれるため、削除の時にもう一度 Apple のサインインを行う（アプリの実装: `lib/firebase/account.dart` の `deleteAccountWithFirebase`）。

## 削除されるデータ

アカウント削除の操作により、次のデータが削除されます。

- アカウント情報（Firebase Authentication のユーザーアカウント）
- サインインに使用した認証情報（Apple ID / Google アカウントとの連携）
- 撮影・選択した元の写真
- 生成したモンスター（名前、図鑑の文章、属性、技、ステータス、レベル、画像）と図鑑・手持ち
- バトル（PvP を含む）の記録
- 通報・ブロックの記録
- 写真から作成した被写体の説明文と写真のハッシュ値

これらは削除操作の後、すみやかに削除されます。一部の写真は、削除に失敗した場合に再試行するため、削除までに時間がかかることがあります。削除後は復元できません。他のユーザーの対戦の相手の候補にも表示されなくなります。

## 削除後も保持されるデータ

次のデータは、アカウントの削除後も残ることがあります。
- 利用状況のイベント（Google Analytics for Firebase）: 提供者の BigQuery に最大 90 日間保存されます。アカウントを識別する情報を含む場合があります。
- クラッシュ情報（Firebase Crashlytics）: Google の定める期間に従って保存されます。

これらからアカウントやモンスターを復元することはできません。
